```
I've been seeing developers around the world turn their cities into beautiful pixel-art maps — London, New York, Málaga and more. Every time, I had the same thought: why isn't there one for an Indian city? 🇮🇳

So I built it. Meet Pixel City Gandhinagar 🏙️

It's an explorable, illustrated map of Gujarat's capital, with every building drawn where it really stands:

🏠 25,969 real buildings and 7,000+ roads from OpenStreetMap, across 61 km²
🌗 Summer, monsoon, winter and night. At night, headlights flow along real roads, metro trains run on Line 2 and windows light up
🛕 Find any temple, hospital, school or metro stop, each with its own little pixel view
🎯 A daily "Find the landmark" game where everyone gets the same three places and you can see other players live
👀 Live pixel avatars of everyone exploring the map right now

A few things I'm proud of:
• It's built entirely from open data, and the whole 2.75-gigapixel city was rendered locally on an 8 GB MacBook
• It's honest about the art: real footprints and positions, and anything illustrated is labelled as such
• It runs on Cloudflare, with the map tiles in R2 and presence and the game in a Durable Object

Explore it: https://pixel-city-gandhinagar.imlistack.workers.dev
Code (open source): https://github.com/ImliStack/Pixel-City-Gandhinagar

If you enjoy it, I'd love three small things 🙏
🎯 Play today's "Find the landmark" game and post your score
🤝 Share it with a friend who'd enjoy exploring Gandhinagar
⭐ Give the project a star on GitHub. It really helps open-source work get seen

Gandhinagar is just the first. Which Indian city would you like to see next? Tell me in the comments 👇

Built under ImliStack — https://imlistack.com

#OpenStreetMap #PixelArt #India #Gandhinagar #WebDevelopment #OpenSource #BuildInPublic #Cloudflare
```
